# Contributing to NVO987

Thank you for your interest in contributing to NVO987 – Culture Visuelle Moderne et Contemporaine.

## Before Contributing

Please review:

- `CODE_OF_CONDUCT.md`
- `SECURITY.md`
- `README.md`

## Types of Contributions

Contributions may include:

- Documentation improvements.
- Corrections of factual or technical errors.
- Accessibility improvements.
- HTML and CSS improvements.
- Metadata improvements.
- Structured-data improvements.
- Feed and indexing improvements.
- Corrections to public links.
- Suggestions concerning digital identity and research interoperability.

## Pull Requests

Please keep changes:

- Focused.
- Clearly documented.
- Technically correct.
- Compatible with the existing design.
- Accessible on desktop and mobile.
- Free from unnecessary third-party dependencies.

## Links and Profiles

When adding an external profile or service:

1. Verify that the URL is publicly accessible.
2. Use the official profile URL whenever possible.
3. Do not add private or sensitive information.
4. Preserve existing naming conventions.
5. Ensure that the link corresponds to the organization or person represented.

## Security Issues

Do not disclose security vulnerabilities through public issues.

Follow the procedure described in `SECURITY.md`.
