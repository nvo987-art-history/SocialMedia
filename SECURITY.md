# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability affecting NVO987 digital infrastructure, please report it responsibly.

Email:

contact@nvo987.fr

Please include:

- A description of the vulnerability.
- The affected URL or component.
- Steps required to reproduce the issue.
- Relevant technical information.
- Any potential security impact.

Do not publicly disclose a vulnerability before it has been reviewed.

## Scope

Security reports may concern:

- `social.media.nvo987.fr`
- `nvo987.fr`
- Related publicly operated NVO987 web infrastructure.

Third-party services linked from the website are operated independently and should be reported according to their respective security policies.

## Responsible Disclosure

NVO987 requests that security researchers:

- Avoid accessing unnecessary personal data.
- Avoid service disruption.
- Avoid destructive testing.
- Avoid social engineering.
- Do not publicly disclose sensitive details before coordination.
